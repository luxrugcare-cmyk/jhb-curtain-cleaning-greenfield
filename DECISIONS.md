# Architecture Decision Register — v1

- D-001: SEO architecture = service × intent × sector × geography; no thin-page factory.
- D-002: Residential and commercial have separate conversion journeys.
- D-003: Attio is the CRM prototype target.
- D-004: No application database until a product requirement justifies one.
- D-005: Next.js App Router frontend.
- D-006: Vercel deployment target.
- D-007: Resend for transactional application email.
- D-008: POPIA consent/suppression is part of the data model.
- D-009: MVP quote funnel uses a form abstraction; this codebase provides a native prototype and API contract so Fillout can be compared or embedded without changing downstream integrations.
- D-010: Public scheduling occurs only after qualification.
- D-011: Sanity preferred for marketing content.
- D-012: GA4 + Search Console primary measurement.
- D-013: n8n preferred only for cross-system workflows not handled natively.
- D-014: Premium Hybrid visual direction.
- D-015: WhatsApp starts as click-to-chat; Cloud API added only when shared inbox/automation volume justifies it.
